# 📡 Wi-Fi Security Scanner

**A White Hat tool to scan Wi-Fi networks and identify security vulnerabilities.**

---

## 📌 Features

- ✅ Scan available Wi-Fi networks
- ✅ Detect encryption type (Open, WEP, WPA2, WPA3)
- ✅ Identify open/unsecured networks
- ✅ Check for WPS vulnerabilities
- ✅ Provide security recommendations

---

## 🚀 Quick Start

```bash
git clone https://github.com/ra1d0n-programmer/wifi-scanner.git
cd wifi-scanner
python scanner.py
```

---

📦 Requirements

· Termux (Android)
· Wi-Fi enabled
· termux-wifi-scan package (on Termux)

```bash
pkg install termux-api
```
